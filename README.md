# FAZO — страница-визитка для Instagram

Одностраничный сайт (аналог Taplink) для цветочного бутика FAZO в Ташкенте. Ссылка ставится в шапку Instagram @fazotashkent.
Статичный сайт: HTML + CSS + чистый JS, без сборки и зависимостей.

```
index.html      — разметка, SEO, Open Graph; первый экран сразу на русском (работает без JS)
styles.css      — стили (цвета — CSS-переменные в :root)
main.js         — язык, статус «Открыто сейчас», карта, отзывы, «Поделиться», аналитика, schema.org
config.js       — ВСЕ данные: тексты RU/UZ, ссылки, телефон, адрес, координаты, часы, отзывы, ID аналитики
assets/         — обложка (AVIF/WebP/JPG, 780 и 1170 px — для экранов 2x и 3x), og-image.jpg, favicon.svg, apple-touch-icon.png
assets/raw/     — исходники картинок
```

## Как менять данные

Всё редактируется в `config.js`. Сохраните файл и обновите страницу — больше ничего трогать не нужно.

**Тексты.** Раздел `i18n`: `ru` — русский, `uz` — узбекский (латиница). Меняйте текст в кавычках, ключи слева не трогайте.
В текстах можно использовать подстановки: `{open}` и `{close}` — часы работы, `{count}` — число оценок.
У русского `reviewsCount` три формы — для 1, 2–4 и 5+ оценок («1 оценка», «3 оценки», «108 оценок»).

**Часы работы.** `hours: { open: "09:00", close: "01:00" }` — время Ташкента. Если `close` меньше `open`, значит закрытие после полуночи; статус «Открыто сейчас / Сейчас закрыто» считается по часовому поясу Ташкента, а не по часам телефона.

**Ссылки и телефон.**
- `telegramCatalog` — канал с каталогом, `telegramManager` — менеджер, `instagram` — профиль.
- `phone` — номер в том виде, как его показывать. Ссылка `tel:` собирается из цифр автоматически.
- `coords` — координаты точки. Из них автоматически строятся ссылки на Яндекс Карты, Google Maps и встроенная карта.
- `rating` — оценка, число оценок и ссылка на отзывы в Яндекс Картах.

**Отзывы.** Массив `reviews`, каждый отзыв — `{ name: "Имя", text: "Текст" }`. Отзывы показываются на языке оригинала в обеих версиях.
Чтобы добавить отзыв — скопируйте блок `{ ... },` и замените имя и текст. Пустой массив `reviews: []` скрывает карточки; заголовок с рейтингом и кнопка «Все отзывы» остаются.

**Адрес для поисковиков** (schema.org) — раздел `seo`. Адрес на странице — ключ `address` в `i18n`.

> Первый экран (подзаголовок, кнопки) продублирован на русском прямо в `index.html` — это запасной вариант для браузеров без JS. Если сильно меняете тексты или ссылки, поправьте и их там же (атрибуты `href` и текст внутри элементов с `data-i18n`), чтобы страница без JS не отставала.

**Язык.** По умолчанию русский (`defaultLang`). Выбор посетителя запоминается. Ссылка сразу на узбекскую версию: `https://ваш-домен/?lang=uz`.

## Аналитика

В `config.js`:

```js
analytics: {
  yandexMetrikaId: "12345678",   // номер счётчика Метрики
  ga4Id: "G-XXXXXXXXXX",         // Measurement ID из GA4
  metaPixelId: "1074223375240694" // ID пикселя Meta (Facebook/Instagram)
}
```

Пустая строка — счётчик не подключается вообще.

**Яндекс Метрика:** metrika.yandex.ru → «Добавить счётчик» → адрес сайта → скопируйте номер счётчика в `yandexMetrikaId`. Код на страницу вставлять не нужно.
Чтобы видеть клики в отчётах, в настройках счётчика → «Цели» создайте цели типа «JavaScript-событие» с идентификаторами:
`catalog`, `tg_manager`, `call`, `maps_yandex`, `maps_google`, `map_show`, `reviews_all`, `share`, `lang_ru`, `lang_uz`.

**Google Analytics 4:** analytics.google.com → «Администратор» → «Потоки данных» → «Веб» → скопируйте идентификатор `G-…` в `ga4Id`. Те же события приходят в GA4 под этими же именами (Отчёты → Взаимодействие → События); нужные можно отметить как ключевые.

**Meta Pixel** (реклама в Instagram/Facebook): ID пикселя — в `metaPixelId`. Пиксель отправляет `PageView` при открытии страницы, а сам скрипт `fbevents.js` грузится после загрузки страницы, в простое браузера — на скорость первого экрана он не влияет. Клики уходят в Meta одновременно с Метрикой и GA4 (та же функция `track` в `main.js`); если кликнуть до загрузки скрипта, событие ждёт в очереди и отправится, как только скрипт загрузится. Если пиксель заблокирован (AdBlock), кнопки работают как обычно.

| Кнопка | Цель Метрики / событие GA4 | Событие Meta |
|---|---|---|
| Открытие страницы | — | `PageView` |
| Каталог букетов | `catalog` | `ViewContent`, `content_name: catalog` |
| Написать менеджеру | `tg_manager` | `Contact`, `content_name: telegram_manager` |
| Позвонить | `call` | `Contact`, `content_name: call` |
| Яндекс Карты | `maps_yandex` | `FindLocation`, `content_name: yandex_maps` |
| Google Maps | `maps_google` | `FindLocation`, `content_name: google_maps` |
| Показать карту | `map_show` | `MapShow` (пользовательское) |
| Все отзывы на Яндекс Картах | `reviews_all` | `ReviewsOpen` (пользовательское) |
| Поделиться ссылкой | `share` | `Share` (пользовательское) |
| Переключение языка RU / UZ | `lang_ru` / `lang_uz` | `LanguageSwitch`, `lang: ru` / `uz` (пользовательское) |

Проверить: Events Manager → источник данных пикселя → «Тестовые события», либо расширение Meta Pixel Helper для Chrome. Пользовательские события (`MapShow`, `ReviewsOpen`, `Share`, `LanguageSwitch`) для оптимизации рекламы заводятся в Events Manager как «Пользовательские конверсии».

**Как отключить пиксель:**
1. В `config.js` поставьте `metaPixelId: ""` — скрипт и все события Meta перестанут отправляться.
2. В `index.html` удалите строку `<noscript><img … src="https://www.facebook.com/tr?id=…"></noscript>` сразу после `<body>` (она срабатывает только у посетителей с выключенным JavaScript).

Чтобы сменить пиксель — замените ID в обоих местах.

## Локальный просмотр

```bash
cd <папка сайта>
npx serve .          # или: python3 -m http.server 8080
```

Для проверки статуса есть параметр `?now=HH:MM` — работает только на localhost:
`http://localhost:8080/?now=03:00` — «Сейчас закрыто», `?now=12:00&lang=uz` — «Hozir ochiq».

## Деплой

### GitHub Pages
1. Создайте репозиторий и загрузите в него содержимое папки `fazo-taplink` (так, чтобы `index.html` лежал в корне).
2. Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Если сайт остаётся в подпапке этого репозитория, удобнее Cloudflare Pages (там можно указать папку).

### Cloudflare Pages
1. dash.cloudflare.com → Workers & Pages → Create → Pages → *Connect to Git* → выберите репозиторий.
2. Framework preset: **None**, Build command: пусто, Build output directory: `fazo-taplink` (или `/`, если файлы в корне).
3. Save and Deploy → сайт появится на `https://<проект>.pages.dev`.
Без Git: *Upload assets* → перетащите папку с файлами.

## Свой домен

**Cloudflare Pages:** проект → Custom domains → Set up a custom domain → введите домен (например, `fazo.uz` или `link.fazo.uz`). Если домен уже в Cloudflare, DNS-запись создастся сама; если нет — добавьте у регистратора CNAME на `<проект>.pages.dev`.

**GitHub Pages:** Settings → Pages → Custom domain → введите домен → Save, включите *Enforce HTTPS*. У регистратора:
- для поддомена (`link.fazo.uz`) — CNAME на `<логин>.github.io`;
- для корневого домена (`fazo.uz`) — четыре A-записи: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.

**Адрес сайта** сейчас `https://fazotashkent.github.io/`. При смене домена замените его в `index.html` (`og:url`, `og:image`, `twitter:image`) и в `config.js` (`siteUrl`) — так превью ссылки будет надёжно показываться в Telegram, Instagram и WhatsApp. Затем поставьте новую ссылку в шапку Instagram.
